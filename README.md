# Ulusal-Football-Club-Chooser
It helps you to choose football club while playing FİFA / FC / eFootball
ULUSAL Team Filter
A professional draw application developed for fair team selection, taking the FIFA Versus experience to the next level.

🚀 Features
Smart Filtering: Instant filtering based on team strength (5, 4.5, 4 Stars).

Mobile Friendly: You can install it on your phone as an application with PWA (Progressive Web App) support.

Quick Draw: Random and fair team assignment.

🛠 How to Use
Go to the ULUSAL Team Filter link.

Select your desired level from the "Team Strength" option.

Press the "DRAW" (KURA ÇEK) button and start the match!

📱 Installation
Android: You can install it by selecting "Add to Home Screen" via the Chrome browser.

iOS: You can install it by selecting "Share" -> "Add to Home Screen" via the Safari browser.
